DIGITAL FOREST PORTFOLIO WEBSITE

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in Chrome to preview the website.
3. To publish it, upload index.html to your hosting provider's public_html folder.

CUSTOMIZE
- Replace the sample portfolio concept tiles with real project images and case studies.
- Update WhatsApp/social links if your contact details change.
- The enquiry form opens WhatsApp with the visitor's message. It does not store submissions on a server.
- This is a static website; no backend or database is required.

Files:
- index.html: complete responsive website (HTML, CSS and JavaScript in one file)
- README.txt: these instructions
